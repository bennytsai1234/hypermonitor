# 策略邏輯說明 (Strategy Logic)

本專案 (`trading_signal`) 是針對 **OKX 永續合約 (Perpetual Swap)** 的自動化交易機器人。
核心邏輯是監聽 Hyperliquid 的市場壓力 (Net Pressure)，並根據壓力變化量 (Delta) 在 OKX 進行跟單交易。

## 1. 訊號來源
- **來源**: Hyperliquid Worker API (`/latest` endpoint)
- **數據**: 監控全體市場的 `long_vol` (多頭成交量) 與 `short_vol` (空頭成交量)。
- **淨壓力 (Net Pressure)**: `long_vol - short_vol`
    - 正值 (+): 多頭強勢
    - 負值 (-): 空頭強勢

## 2. 交易觸發條件
機器人會持續輪詢 (Polling) 最新數據，當滿足以下條件時觸發交易：

1.  **變化量檢測**: 計算當前淨壓力與上一次記錄的淨壓力的差值 (`Delta`)。
2.  **最小門檻 (Min Delta)**: `Delta` 的絕對值必須大於 `MIN_DELTA` (預設 500,000)。
    - 過小的波動會被忽略，以節省手續費。
3.  **最大門檻 (Max Delta)**: `Delta` 的絕對值必須小於 80,000,000 (8000萬)。
    - 過大的波動 (> 8000萬) 被視為極端異常，**直接跳過不交易**。

## 3. 倉位計算 (資金管理)
本機器人採用 **線性比例 (Linear Ratio)** 方式計算開倉金額：

- **公式**: `Order Value (USD) = |Delta| × RATIO`
- **OKX 特別設定**:
    - 本專案設定為 **Binance 倉位的 1/10**。
    - **Ratio**: `0.00002`
    - **範例**:
        - Delta = 1,000,000 (100萬)
        - 下單價值 = 1,000,000 × 0.00002 = **$20 USD** (約 0.0003 BTC)
    - **槓桿**: 預設 10x (僅影響保證金佔用，不影響下單的名義價值)。

## 4. 下單策略 (混合模式 Hybrid)
機器人根據訊號強度 (Delta) 自動切換下單模式，依據 `MARKET_THRESHOLD` (預設 500萬) 判斷：

### 情況 A: 大資金訊號 (Delta ≥ 500萬)
- **策略**: **市價單 (Market Order)** 直接進場。
- **原因**: 訊號強烈，行情可能迅速發動，必須確保即時成交，不錯過大行情。
- **代價**: 支付 Taker 手續費。

### 情況 B: 小資金訊號 (Delta < 500萬)
- **策略**: **限價單 (Limit Order) - 6分鐘 K線定價**。
- **邏輯**:
  1.  鎖定 **前一個完整的 6 分鐘區間**。
  2.  **做多 (BUY)**: 限價單掛在 6 分鐘區間的 **最低價 (Low)** (若當前價格更低，則掛當前價格)。
  3.  **做空 (SELL)**: 限價單掛在 6 分鐘區間的 **最高價 (High)** (若當前價格更高，則掛當前價格)。
- **原因**: 訊號較弱，嘗試在近期極值進場以獲得更好價格，但使用標準 Limit 單確保不被拒絕 (移除 Post-Only 限制)。
- **失效處理**: 若 API 抓取 K 線失效，則直接以當前價格下 Limit 單。

## 5. 風險控制
- **無上限機制**: 為了捕捉超級大戶訊號，已移除單筆金額上限。下單金額完全由 `RATIO` × `Delta` 決定。
- **DRY_RUN**: 模擬模式，只會打印日誌，不會真實發送訂單。
